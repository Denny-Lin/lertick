# Naming check evidence

`search-evidence.json` records checks made on 2026-10-09 before publication of
Lertick. The [12-name comparison](../../docs/NAMING.md) explains ranking and the
independent decision. Repository-name searches match substrings; results were
reviewed for exact basenames. Web search notes distinguish actual brands from
OCR, surnames and single code identifiers.

RDAP endpoints come from the IANA bootstrap and primary registries. HTTP 404
means no registration record, not guaranteed registrar availability, ordinary
price or non-reservation. Repeat 429 checks retain earlier successful observations.
No domain was purchased. Searches can change after this repository is published.
